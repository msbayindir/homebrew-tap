# msbayindir/homebrew-tap

Homebrew formulae for [panosync](https://github.com/msbayindir/panosync), end-to-end encrypted
clipboard sync between macOS, Linux and Windows.

```bash
brew install msbayindir/tap/panosync
brew services start panosync   # start now and at every login
```

`Formula/panosync.rb` is generated by panosync's release workflow from the release's
`SHA256SUMS` and installs the prebuilt binaries from
[GitHub Releases](https://github.com/msbayindir/panosync/releases). Please open issues in the
[panosync repository](https://github.com/msbayindir/panosync/issues), not here.
